> **Note:** This is an abandoned project. Most of the features are finished, but it was not brought to a perfect state.

## This project is a translator of text from a screenshot
The project was developed for fun and personal growth. Right now I am not interested in developing software with Python, so the project stays in its last version, and some tools no longer work because the code, APIs, and approaches have become outdated. At the time of development, AI such as ChatGPT, Claude, and others either did not exist or I did not know about it. So the code of the project is 97% hand-written, based on my small programming experience at that time.

## 🚀 Technical features:
- Automatic text extraction from a screenshot, specifically from an image file.
- Automatic translation of text in a selected coordinate area.
- Function to pin the translator interface on top of all windows.
- Ability to shrink the translator interface so that only the translated text is visible in a small window.
- Settings with the ability to choose between several different translation engines.
- Hotkey settings.
- Automatic translation of new images in a specific folder.
- Ability to choose different interface themes.

It was also created with the idea that anyone can make their own theme using Qt Designer and add it to the translator. Right now this is implemented and works, but code changes may be needed so that the theme code generated by an updated version of the tool can run in a translator built for the 2021 version of the program.

## 🛠️ Tools used:
- The interface is built with `PyQt5` and `Qt Designer`
- For text extraction from images, `Tesseract` and `pytesseract` are used
- Translation: libraries `deep_translator` and `deepl`
- Other tools for various working purposes (listed in the dependencies together with the others)
### Dependencies:
- Python 3.15.2
- `pip install psutil pyqt5 pytesseract colorama pillow deep_translator winotify pyautogui deepl keyboard`
