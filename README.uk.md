> **Примітка:** Це закинутий проєкт, Більшість функцій готова, але не доведена до ідеального стану. 

## Цей проєкт є перекладачем тексту зі знімка екрану
Проєкт розроблявся для задоволення та особистого розвитку, наразі мене не цікавить розробка програмного забезпечення за допомоги Python тому проєкт залишається його останньою версією й деякі інструменти вже не працюють через застаріння коду, API, підходів. На момент розробки проєкту не існувало, або я не знав про ШІ як на приклад: ChatGPT, Claude, інші. Тому код проєкту це 97% ручного написання за допомоги мого невеликого досвіду програмування на той час.

## 🚀 Технічні можливості:
- Автоматичний збір тексту з знімка, а саме файла зображення.
- Автоматична можливість перекладу тексту у виділеній зоні координат.
- Функція закріплення інтерфейсу перекладача поверх всіх вікон.
- Можливість зменшення інтерфейсу перекладача з можливістю бачити тільки перекладений текст у маленькому вікні
- Налаштування з можливістю вибору декількох різних рушіїв перекладу.
- Налаштування зміни гарячих клавіш
- Автоматичний переклад нових зоображень у певній теці
- Можливість обирати різні теми інтерфейсу
Він створювався також з ідеєю того, що будь хто може зробити свою тему за допомоги Qt Designer та додати її в перекладач. Наразі це реалізовано та працює, але можуть потребуватися правки через код, щоб згенерований код теми за допомоги оновленого інструмента міг запуститися на перекладачу розрахованому на версію програми 2021 року.

## 🛠️ Використані інструменти:
- Інтерфейс відтворено за допомоги `PyQt5`, та `Qt Designer`
- Для збіру тексту з зображення використано `Tesseract`, та `pytesseract`
- Переклад: бібліотека - `deep_translator`, та `deepl`
- Інші інструменти для різних робочих цілей (зазначені у залежностях разом з іншими)
### Залежності: 
- Python 3.15.2
- `pip install psutil pyqt5 pytesseract colorama pillow deep_translator winotify pyautogui deepl keyboard`
